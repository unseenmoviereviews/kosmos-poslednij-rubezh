# Бортовой журнал TOS

Тепловая карта рейтингов IMDb всех 79 серий «Звёздного пути» (1966–1969) и карта связей персонажей. Неофициальный некоммерческий фан-проект.

## Публикация на GitHub Pages
1. Создайте репозиторий и положите в корень `index.html`.
2. Settings → Pages → Deploy from branch → `main` / `root`.
3. Сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.
